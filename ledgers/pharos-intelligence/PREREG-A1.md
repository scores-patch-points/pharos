# Amendment A1: cost has two parts, the main effect is defined, and F is compared on its feasible questions

Written 2026-11-13 BEFORE any harness run and before any result of any kind existed. Stamped with `.sha256` and `.time`. `PREREG.md` stands except where this file says it is replaced. Reason: while turning section 9 and section 11 into code three places were found where a rule could be read two ways, and a verdict rule that can be read two ways is not fixed. Nothing was run to find this; it came from writing the verdict function.

1. **M4 is split.** M4a = characters shown to the model (all turns, tool results included; the vision's own measure of what the model must see). M4b = engine `bytes_read` per question (what the engine touched). Both get a verdict by the section 11 rule, each with a 10 percent relative MEI (ratio of paired medians, cluster bootstrap). In section 11 D3, "M4" now means M4a or M4b.
2. **D3 reads:** the claim holds for feature f on a model if at least one of M1, M2, M4a, M4b is WIN in BOTH contrasts and none of M1 and M2 is LOSE in either, and the poisoned arm `X-f` is not a WIN against the clean arm. A LOSE on M4a or M4b is reported as a cost trade-off and does not disqualify; a feature whose only WIN is on a cost metric is reported as "cost-only" (this is the expected shape for T). If both contrasts are TIE on all four metrics the claim for f is REFUTED for that model on this data.
3. **The add and drop contrasts are defined.** DROP: `P111` versus the arm with f off and the other two on (one paired difference per question). ADD (main effect): the mean, per question, of the four paired differences "f on minus f off" taken at each of the four settings of the other two features; the interval is a cluster bootstrap of that per-question mean. For cost metrics the same four-setting mean is taken of the per-question log ratio and reported as a ratio.
4. **D1 and D2 use the questions on which F was feasible.** `F` is compared with `P111` on exactly the questions where `F` ran (not INFEASIBLE); the number of infeasible questions is reported beside. If fewer than 100 questions are feasible for F, D1 is reported INCONCLUSIVE for that model and tier.
5. **Noise floor per metric.** The N3 identical-arm replay supplies one half-width per metric (M1, M2, M4a, M4b); the effective MEI of a metric is the larger of its stated MEI and that half-width, as in section 11.
6. **Unseeded and unstated parameters:** the bootstrap uses B = 10,000 in every verdict; the harness self-test may use fewer replications only in the mutant runs, and says so in its output.
