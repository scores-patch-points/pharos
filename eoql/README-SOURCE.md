# Where this folder comes from

This is a copy of `ledgers/pharos-eoql/` from the working folder, made on 2026-11-14 when the work moved into the pharos repo. Its paths still refer to `ledgers/...`, the place where it was made.

**Left out, so the repo can be public:**
- the parked EOQL/1 build's generated outputs (`answers/`, `mut/`, `out/`, every `*.db`);
- its question and review sets (`qa/`, `review/`), which hold material from private logs;
- its test suites (`test/`, `test-builder/`);
- the pinned copies of EOQL v1. Those come from the public repo eo-activibase (an earlier public repository by the same author); `prior/eo-activibase/SOURCE.txt` and `prior/PINS.sha256` name the exact files and hashes.

All of these stay in the working folder.

Names that the private-names list flags, and home paths, are replaced with `[name]`, `<user>`, `~` and `<workdir>`. Hash pins that cover edited or left-out files therefore will not match in this copy. The originals still match.

**What is here:**
- `EOQL-COMMANDS.html`: the 27 commands, OP- (Ground), OP (Figure) and OP+ (Pattern).
- `PREREG-27.md`: the falsification test of "only 27 commands".
- `SIG-ANSWER.md`: the team's answer on SIG, with every ruling and measurement.
- `PREREG.md` and its amendments A1 to A4.
- `SPEC*.md`: the parked EOQL/1 specification.
- `design/`: the design round.
- `prior/`: pinned sources, including the project owner's design notes.
- `src/`, `bin/`, `adapters/`, `vendor/`: the parked build's code.

Companion folders in this repo: `research/janus-three-math/` and `docs/essays/`.
